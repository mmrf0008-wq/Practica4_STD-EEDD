Carga el fichero CSV indicado, mostrando cada especie por pantalla.

Cada línea se analiza y, si tiene el número de campos esperado, se construye una Especie que se almacena en el VDinamico Las filas con un número de campos distinto del esperado se descartan (ver filasDescartadas()).

Parameters
rutaFicheroRuta del fichero CSV a leer.
Returns
true si el fichero se ha podido abrir, false en caso contrario.

Carga los parques desde un fichero CSV (código y nombre) y los añade a la lista.

Se salta la cabecera (eliminando el BOM si existe) y se descartan las filas con menos de 2 campos.
